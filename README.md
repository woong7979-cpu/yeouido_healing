# 여의도공원 · 달리고, 따릉이 타고, 달멍·불꽃멍 (Yeouido Healing World)

서울 여의도공원을 OpenStreetMap 실제 지도로 옮긴 3D 웹 힐링 월드입니다. 룸피니공원 힐링 월드(lumpinihealing.vercel.app)와 같은 엔진(three.js r160)으로 지도·랜드마크·이벤트만 바꿨어요. 설치·빌드 없음 — 정적 파일만.

| 파일 | 내용 |
|---|---|
| `index.html` | 첫 화면 — 버전 고르기 |
| `character.html` | 캐릭터 버전 (귀여운 캐릭터, 가벼움) |
| `people.html` | 사람 버전 (실사 사람 모델) |
| `music/` | 멍때리기 음악 6곡(`yd_*.mp3`) + 완주 축하곡 |
| `models/` | 사람 3D 모델·동작 (base64 JSON) |
| `shots/`, `tex/` | 첫 화면 그림 · 바닥 텍스처 |

## 들어 있는 것
- 2.6km 「여의도공원 자전거길」 루프 (OSM), 🚲 따릉이 타기, 자전거 타는 사람들
- 서울달(지름 22m 계류식 기구) — 12:00–22:00, 20분마다 130m까지 상승, 밤엔 빛나요
- 세종대왕 동상 + 앙부일구·자격루·혼천의·측우기, C-47 비행기 전시관, 태극기 게양대, 여의정·사모정
- 멍 스팟 5곳: 연못멍 · 노을멍 · 물멍 · 단풍멍 · 불꽃멍(🎆 불꽃 쏘기, 불꽃축제 바로가기)
- 직장인 점심 산책(11:50–13:05), 퇴근길 러닝크루, 저녁 에어로빅, 모닝런 2.6K, 청둥오리 컬렉션
- 가을(11월) 서울 해 시간 · 단풍·은행나무 · 서울 실제 날씨(Open-Meteo)

## 배포
- 빌드 명령 없음, 출력 폴더 = 저장소 맨 위(root). Vercel: Import → Framework `Other` → Deploy.
- GitHub 웹 업로드는 폴더째 끌어다 놓기, 한 번에 너무 많으면 폴더별로 나눠 커밋.
